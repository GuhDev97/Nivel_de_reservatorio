# Simulador de Nível de Reservatório 💧

Um script simples em Python desenvolvido para demonstrar o monitoramento de níveis de reservatórios com saída colorida no terminal, utilizando a biblioteca `colorama`.

## 🚀 Tecnologias Utilizadas

* **Python 3.x**
* **Colorama** (para estilização de texto no terminal)

---

## 📋 Pré-requisitos

Antes de executar o projeto, você precisará ter o Python instalado em sua máquina, junto com a biblioteca `colorama`. 

Você pode instalar a dependência executando o seguinte comando no seu terminal:

```bash
pip install colorama
